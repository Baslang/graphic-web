# XLANG Designer — Motion-led portfolio

A responsive static portfolio for XLANG Designer, featuring CSS-built concept mockups, 3D-inspired hero art, animated reveals, portfolio filtering, mobile navigation and reduced-motion support.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual system, motion and CSS mockups
- `script.js` — navigation, portfolio filters, scroll reveals and subtle pointer motion
- `hero-art.png` — custom XLANG hero artwork

## Deploy to Render
This is a static site. In Render, set **Build Command** to blank and **Publish Directory** to `.`. Keep the files in the same repository root: `index.html`, `styles.css`, `script.js`, and `hero-art.png`.

## Before promoting the site
- Confirm the contact email `hello@xlangd.com` is one you control, or replace it with your preferred business email.
- Add real project case studies and label speculative concepts honestly. The concepts currently shown are visual portfolio concepts, not claims of client commissions.
- Add verified LinkedIn, Fiverr and other professional profile links when ready.
- The site is static and does not currently include a backend contact form.
